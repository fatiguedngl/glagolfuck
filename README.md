# ⰔⰕⰀⰁⰘⰙⰊⰋ GlagolFuck (Славянский Brainfuck)

Славянский эзотерический язык программирования, основанный на синтаксисе классического **Brainfuck**, но использующий древние онфимные символы круглой глаголицы и их ASCII-транслит. Рекомендуем на глаголице.

Интерпретатор бесшовно понимает как нативные UTF-8 символы глаголицы, так и текстовый транслит английскими буквами, но в версии Deluxe всё будет с компилятором.

## 📜 Синтаксис и Маппинг команд

| Команда BF | Глаголица | Транслит | Описание |
| :---: | :---: | :---: | :--- |
| `>` | Ⱄ | `Slovo` | Сдвиг указателя ленты вправо |
| `<` | Ⱅ | `Tverdo` | Сдвиг указателя ленты влево |
| `+` | Ⰰ | `Az` | Инкремент значения в текущей ячейке |
| `-` | Ⰱ | `Vedi` | Декремент значения в текущей ячейке |
| `.` | Ⱈ | `Her` | Вывод символа на экран (ASCII) |
| `,` | Ⱉ | `Omega` | Ввод символа из консоли |
| `[` | Ⰺ | `Izhe` | Начало цикла (переход вперед, если ячейка == 0) |
| `]` | Ⰻ | `I` | Конец цикла (переход назад, если ячейка != 0) |

*Любые сторонние символы, пробелы, цифры и переводы строк интерпретатором игнорируются, что позволяет писать полноценные славянские комментарии прямо внутри кода.*

## 💻 Использование

### 1. Запуск интерпретатора
Вы можете запускать готовые свитки кода с расширением `.gf` через интерпретатор:
```bash
python glagolfuck.py имя_файла.gf
```

### 2. Использование транслятора (Трансглагола)
Чтобы не писать циклы руками, используйте `transglagol.py` для мгновенной конвертации обычного Brainfuck в славянский стиль и обратно:

* **В неубиваемый транслит:** `python transglagol.py to-translit file.bf`
* **В нативную UTF-8 глаголицу:** `python transglagol.py to-glagol file.bf`
* **Из глаголицы обратно в BF:** `python transglagol.py from-slav file.gf`

## 📜 Историческое обоснование синтаксиса / Historical Philosophy

Каждая команда в **GlagolFuck** выбрана не случайно. В глаголице у каждой буквы есть своё имя и глубокий сакральный или бытовой смысл. Мы сохранили эту логику для управления лентой памяти:

### На русском:
* **Ⰰ [Аз] (`+`)** — Означает «Я», начало, первый шаг, сотворение. Идеально подходит для создания/увеличения значения в ячейке.
* **Ⰱ [Веди] (`-`)** — Означает «Ведать», познавать глубину или уменьшать сущность до её истоков. 
* **Ⱄ [Слово] (`>`)** — Символизирует изречение, трансляцию мысли, движение вперёд и распространение информации (сдвиг указателя вправо).
* **Ⱅ [Твердо] (`<`)** — Символизирует опору, нерушимый фундамент, возврат к истокам и стабильности (сдвиг указателя влево).
* **Ⱈ [Херъ] (`.`)** — Исторически знак перекрестия (отметка), фиксация. В нашем контексте — явление знака миру, то есть вывод символа на экран.
* **Ⱉ [Омега / От] (`,`)** — Означает принятие, исхождение извне внутрь. Используется для ввода данных от пользователя.
* **Ⰺ [Иже] (`[`)** — Союз «И», связующее звено, начало объединяющей мысли. Открывает цикл.
* **Ⰻ [И] (`]`)** — Завершение союза, замыкание мысли. Закрывает цикл.

### In English (For Global Community):
* **Ⰰ [Az] (`+`)** — Means "I" or "The Beginning". Represents creation and the first step (Increment).
* **Ⰱ [Vedi] (`-`)** — Means "To Know" or "To See depth". Represents subdual or reduction to the roots (Decrement).
* **Ⱄ [Slovo] (`>`)** — Means "The Word". Represents the flow of speech, moving forward and spreading knowledge (Pointer Right).
* **Ⱅ [Tverdo] (`<`)** — Means "Firm" or "The Ground". Represents standing ground, returning to structural stability and origins (Pointer Left).
* **Ⱈ [Her] (`.`)** — Historically a cross-mark or fixation sign. Represents manifestation of a letter, hence printing to the screen (Output).
* **Ⱉ [Omega / Ot] (`,`)** — Means "From / Out of". Represents taking inside from an external source (Input).
* **Ⰺ [Izhe] (`[`)** — Means "And / Which". A connecting conjunction that bounds ideas together. Starts the loop.
* **Ⰻ [I] (`]`)** — The completion of the binding. Ends the loop.
